# Algorithm Specifications and PDD Rates

A comprehensive table containing all algorithms evaluated in the
article. It containing algorithm names as well as their constituting
components including operationalisations of IADL deficit, global
cognitive deficit and cognitive impairment according to monitored
domains.

## Usage

``` r
rates
```

## Format

A tibble with 68 rows and 11 columns:

- type:

  Character; name of the algorithm.

- perc:

  Numeric; raw PDD rate.

- Global:

  Character; operationalisation of global cognitive deficit.

- Executive:

  Character; operationalisation of executive deficit.

- Construction:

  Character; operationalisation of visuoconstruction deficit.

- Memory:

  Character; operationalisation of memory deficit.

- Language:

  Character; operationalisation of language deficit.

- IADL:

  Character; operationalisation of IADL deficit.

- N:

  Integer; number of observations for a given algorithm.

- Rate:

  Character; number and percentage of patients with probable PDD.

## Source

Generated by the targets pipeline in `_targets.R`.

## Details

Since demcrit v2.0.0, MoCA-based algorithms apply the global criterion
MoCA \< 27, as stated in Table 1 of the article. The values printed in
the article are available as
[rates_published](https://josefmana.github.io/demcrit/reference/rates_published.md);
see
[`vignette("corrections")`](https://josefmana.github.io/demcrit/articles/corrections.md).
