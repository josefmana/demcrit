# Published Table of Pairwise Concordance Measures (v1.2.0)

The version of
[concords](https://josefmana.github.io/demcrit/reference/concords.md)
distributed with demcrit v1.2.0, i.e., the values underlying the
concordance results printed in Mana et al. (2026). These statistics were
computed on pairwise available cases (N between 190 and 202 per pair of
algorithms) rather than on the 190 complete cases described in the
article, and with MoCA-based algorithms applying the global criterion
MoCA \< 26. Kept for comparison only; use
[concords](https://josefmana.github.io/demcrit/reference/concords.md)
for analyses. See
[`vignette("corrections")`](https://josefmana.github.io/demcrit/articles/corrections.md)
for details.

## Usage

``` r
concords_published
```

## Format

A tibble with the same structure as
[concords](https://josefmana.github.io/demcrit/reference/concords.md).
