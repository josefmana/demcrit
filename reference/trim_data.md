# Prepare complete data

Given a set o patients with incomplete PDD data, extracts data set
containing only complete cases. Can be applied to raw (generated by
`prepare_data`) or pre-processed (generated by `diagnose_pdd_sample`)
PDD data.

## Usage

``` r
trim_data(d0, inc)
```

## Arguments

- d0:

  Data to be trimmed

- inc:

  Incomplete cases, e.g., generated by `find_incomplete`

## Value

The same data as input but with complete cases (regarding /PDD data)
only.
