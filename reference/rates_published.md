# Published Algorithm Specifications and PDD Rates (v1.2.0)

The version of
[rates](https://josefmana.github.io/demcrit/reference/rates.md)
distributed with demcrit v1.2.0, i.e., the values printed in Mana et al.
(2026). In these data, MoCA-based algorithms applied the global
criterion MoCA \< 26, although Table 1 of the article states MoCA \< 27.
Kept for comparison only; use
[rates](https://josefmana.github.io/demcrit/reference/rates.md) for
analyses. See
[`vignette("corrections")`](https://josefmana.github.io/demcrit/articles/corrections.md)
for details.

## Usage

``` r
rates_published
```

## Format

A tibble with the same structure as
[rates](https://josefmana.github.io/demcrit/reference/rates.md).

## Source

demcrit v1.2.0 (commit 1843263).
